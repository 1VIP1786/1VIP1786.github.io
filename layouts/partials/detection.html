ProcessGUID Correlation

Sysmon assigns a unique ProcessGuid to every process execution. Correlating every subsequent event — child processes, network connections, file writes, registry changes, DNS queries — against that same ProcessGuid reconstructs the full behavioral story of one execution, rather than looking at isolated log lines. This is the core technique behind every investigation in this portfolio.

This is a detection-engineering / research technique applied manually in Kibana queries — not a claim of having built a production XDR platform.
