About

Security operations first, infrastructure second.

I'm an M.Tech Cybersecurity student who builds the systems I write about. Instead of reading about SIEM pipelines, I built one — Sysmon and Winlogbeat feeding Logstash into Elasticsearch, investigated through Kibana. Instead of reading about MITRE ATT&CK, I simulated ten-plus techniques with Atomic Red Team and traced each one back through the telemetry it generated.

My focus areas are SOC operations, SIEM-based detection, threat hunting, detection engineering, incident investigation, network security, and vulnerability assessment fundamentals — the core skill set behind Security Analyst, SOC Analyst, and Information Security Consulting roles.

Before cybersecurity, I built a solid foundation in IT infrastructure — Linux and Windows administration, networking, cloud (AWS/GCP), containers, and CI/CD automation. That background doesn't sit at the center of this portfolio, but it shapes how I think about detections: I understand the systems generating the telemetry, not just the alerts they produce.

Career trajectory

IT Foundation ↓ Systems / Infrastructure ↓ Cybersecurity ↓ SOC · SIEM ↓ Threat Detection & Hunting ↓ Detection / Security Engineering
