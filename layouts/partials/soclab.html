Setup & Scope

  • Windows VM instrumented with Sysmon using a tuned configuration for high-value event types.
  • Winlogbeat forwards Sysmon + Windows Event Logs to a Logstash pipeline for parsing/enrichment.
  • Elasticsearch indexes the telemetry; Kibana dashboards and Discover are used for investigation.
  • Atomic Red Team executes individual ATT&CK techniques to generate realistic adversary telemetry.

Lessons Learned & Limitations

  • Sysmon config tuning matters — default configs are noisy; field selection drives detection quality.
  • ProcessGuid correlation (see below) is essential once event volume grows past a few hundred events.
  • This is a single-host lab, not a multi-endpoint production SOC — detections aren't yet tested at scale.
  • Next step: version-controlled detection rules instead of ad-hoc Kibana queries (see Roadmap).
